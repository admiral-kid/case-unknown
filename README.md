# CASE UNKNOWN

> その会社には、まだ誰も気づいていない問題がある。

ビジネスコンサルタントとして、企業の「原因のよく分からない問題」を解き明かすブラウザゲームです。
証言・数字・資料・現場を調べ、仮説を検証して本当の問題を突き止め、最終報告書で施策を提案し、3か月の実行支援まで見届けます。

**▶ 遊ぶ: https://admiral-kid.github.io/case-unknown/**

- TUTORIAL「客は減っていない。それなのに、なぜ売上が落ちた？」（10分ほど）：先輩の案内つきで、調査から報告・実行支援までをひと通り体験
- CASE 01「問い合わせは増えていない。それなのに、なぜ残業は25%増えた？」（15〜30分）
- PC・スマートフォン対応（ホーム画面に追加するとアプリのように起動できます）。進行はブラウザに自動保存され、途中セーブや、工数を使う前への巻き戻しもできます
- 委託費の範囲で調べきれるかも腕の見せどころ（超えた工数は事務所の赤字）
- 登場する企業・人物・製品はすべて架空です。人物・背景の画像は画像生成 AI で作成しています

このリポジトリは公開用のビルド結果だけを置いています。
